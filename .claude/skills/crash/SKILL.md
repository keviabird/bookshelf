Исправь ошибку по описанию или логу: $ARGUMENTS

1. Создай ветку bugfix/<название>.
2. Напиши тест, воспроизводящий ошибку, и убедись, что он падает —
   прогони только его сьют (`-only-testing:BookshelfTests/<Suite>`):
   - логика — Swift Testing в подходящем сьюте;
   - хранилище и ошибки записи — `TestStore` с `failSaves`, проверка через `persistedBooks()`;
   - XCUITest — только если ошибка воспроизводится лишь в UI.
   Не удаётся воспроизвести — остановись и опиши, что пробовал. Не чини вслепую.
3. Найди причину: одним-двумя предложениями объясни, ПОЧЕМУ возникает
   ошибка, а не только где. Найди в проекте другие места с тем же паттерном.
4. Покажи: причину, падающий тест, план исправления, похожие места.
   Остановись до моего одобрения.
5. Исправь причину. Запрещено: `?? значение` для подавления nil, `try?` для
   проглатывания ошибок, удаление проверок или ослабление теста.
6. Новый тест проходит → собери проект без предупреждений Swift 6 →
   полный прогон BookshelfTests. Падающий тест — отдельным коммитом перед
   исправлением. Затем открой PR.
