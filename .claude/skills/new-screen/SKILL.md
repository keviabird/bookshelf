Сверстай экран по макету: $ARGUMENTS

1. Создай ветку feature/<имя-экрана>.
2. Изучи макет через Figma MCP. Если фрейм без auto layout — используй его
   только как визуальный ориентир: никаких .offset/.position, строй на стеках.
3. Цвета и шрифты — только из существующего набора (`DESIGN_SYSTEM.md`,
   `Assets.xcassets`); прочитай `DESIGN_SYSTEM.md` до начала вёрстки.
   Недостающие добавь туда же, не заводи параллельный.
4. Переиспользуй существующие компоненты (ячейки, чипсы) вместо копий.
5. Для свежих API iOS 26 (Liquid Glass) — только системные модификаторы.
   Deployment target — iOS 17: оборачивай их в `if #available(iOS 26, *)`
   и давай фолбэк для старых версий.
6. Архитектура: у экрана свой ViewModel (`@Observable`, `@MainActor`),
   его создаёт родительский ViewModel. View не обращается к SwiftData
   напрямую — только через ViewModel и `BookRepository`.
7. Новым интерактивным элементам дай идентификаторы из
   `Shared/AccessibilityID.swift`, чтобы UI-тесты не искали по тексту.
8. Покажи план и остановись до моего одобрения.
9. После реализации: собери проект, проверь отсутствие предупреждений
   Swift 6, прогони полный `BookshelfTests` — коммит только при зелёных
   тестах. Коммиты на английском, в повелительном наклонении. Затем открой PR.
